# פריסה ל-Render (שכבה חינמית)

התיקייה הזו היא **עטיפת פריסה בלבד**. אף קובץ בתוך `RAG_Agent_Project/` לא שונה — הפרויקט המקורי ממשיך לרוץ מקומית בדיוק כמו קודם (`python ingest_local.py` ואז `python app_local.py`).

`render/app.py` הוא נקודת הכניסה של Render: הוא בונה את `storage_local` אם היא חסרה, טוען את האינדקס, ומעלה את אותו ממשק Gradio עם אותה כותרת, אותן תוויות בעברית ואותן שאלות לדוגמה.

**למה הוסר ה-SSL bypass:** הקוד המקומי מבטל אימות תעודות כדי לעקוף את ה-proxy של הרשת במשרד. על שרת ציבורי זו חולשה אמיתית — כל מי שיושב על המסלול יכול ליירט את הקריאות ל-Cohere ואת מפתח ה-API. ל-Linux של Render יש CA bundle תקין, ולכן העטיפה הזו לא מכילה אף שורה מהבלוק הזה. גם `python-certifi-win32` הוסר — הוא חבילת Windows בלבד.

**מפתח ה-API** לא נמצא בקוד. הוא מוגדר ב-Render: Dashboard ← השירות ← Environment ← `COHERE_API_KEY`.

**השכבה החינמית נרדמת:** אחרי 15 דקות ללא תנועה Render מכבה את השירות, והכניסה הבאה לוקחת כ-50 שניות עד להתעוררות. יש על כך הודעה בעברית בתוך הממשק עצמו, כדי שמבקר לא יחשוב שהאתר תקול.

**איך לפרוס מחדש:** כל `git push` ל-`main` מפעיל deploy אוטומטי. לפריסה ידנית — Dashboard ← השירות ← Manual Deploy.

**אחרי הוספת מסמכים ל-`dummy_data/`:** ה-build בונה את האינדקס מחדש, אז מספיק push. אם רוצים בנייה מאפס — Manual Deploy ← Clear build cache & deploy.
